# Scoop Bucket for Rux

A [Scoop](https://scoop.sh) bucket containing the [Rux](https://github.com/rux-lang/Rux) compiler package for Windows.

## Usage

Add this bucket to Scoop:

```powershell
scoop bucket add rux-lang https://github.com/rux-lang/Scoop
```

Install the Rux compiler:

```powershell
scoop install rux-lang/rux
```

## Packages

| Package | Description  | Version |
| ------- | ------------ | ------- |
| `rux`   | Rux compiler | Latest  |

## Requirements

- Windows (64-bit)
- [Scoop](https://scoop.sh) package manager
